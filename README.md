# e/acc

The source for [eacc.space](https://eacc.space): an optimistic, technology-forward introduction to effective accelerationism.

Built with TypeScript, Svelte 5, and SvelteKit. Every page is statically generated with a persistent trailing-slash URL and deployed to GitHub Pages from `main`.

## Local development

```sh
npm install
npm run dev
```

Run `npm run check` and `npm run build` before publishing.
